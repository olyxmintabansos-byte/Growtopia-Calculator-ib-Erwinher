A modern, responsive all-in-one **Growtopia Farming Calculator** inspired by Erwinher and redesigned by Olyx. Easily calculate block breaking gem/seed yields, tree harvesting multipliers, and full farm loop profitabilities.

---

## ✨ Features

- 🔨 **Break Only Calculator:**
  - Presets for popular farmables (Pepper, Laser Grid, Chandelier).
  - Ancestral Tesseract (Level 0 - 5) support.
  - Multipliers for Lucky Clover, Buddy Head, Wishing Star, and Guild Potion (+20%).
  - Converts estimated gems to equivalent World Locks (WL).
- 🌾 **Harvest Only Calculator:**
  - Tree yield calculation with Harvester of Sorrows / Fuel Pack bonus multipliers.
  - Estimated manual harvest time calculator.
- 🚜 **Full Cycle Simulation (Plant ➔ Harvest ➔ Break):**
  - Accurately tracks net seed growth percentages and total gem yields per farming loop.
- 📱 **Modern Dark UI:** Styled with Tailwind CSS and Lucide Icons, responsive on all devices.
